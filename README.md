# Aymara and Quechua corpus tools

Tools to clean, align and publish Aymara and Quechua text corpora for public-service language models.

## Overview

Command-line tools for building parallel corpora from public documents, with consent and licence tracking for every source.

## Interfaces

Protocol: `cli`. Languages: ay, qu, es.
